# 修炼体系

---

## 大一统的由来

归墟发展一亿年，各文明原本的修炼法门基本趋同。原因有三：

1. 器灵最初就传授了高效的方法
2. 一亿年的交流与竞争，低效路径被淘汰
3. 能量本身有固定的规律，最优解只有一个

所以趋同不是被强制的，是被筛出来的。

---

## 三元

所有修炼都围绕三个东西展开，合称**三元**：

### 神 —— 控制器

- 即意识、精神
- 决定**能量吸收的速度与质量**
- 神越强，吸收越快，能吸收的能量等级越高、越精纯
- 对应天赋：天赋就是神与归墟的契合度

### 体 —— 承载

- 即肉身、容器
- 决定**能量上限与恢复速度**
- 体越大，能容纳的能量越多，消耗后恢复越快
- 体的本质是肉体，能量的改造让体逐步扩容

### 气 —— 输出

- 即能量、燃料
- 决定**等级与战斗力**
- 气就是体内积累的能量
- 气的等级和精纯度直接决定能打出多强的战斗力

---

## 修炼的循环

```
神提升
  ↓
吸收能量速度与质量提升
  ↓
气积累（等级与战斗力上升）
  ↓
能量改造肉体 → 体扩容
  ↓
能承载更高等级的能量
  ↓
（回到神提升，进入下一轮）
```

三元互相咬合，缺一个都走不远：
- 神弱：吸收慢，卡在低等级能量
- 体小：能量装不下，溢出浪费
- 气少：等级低，战斗力上不去

---

## 归墟与现实

### 在归墟内

- 意识投射进入，肉身留在现实
- 归墟内获得**道具带不回去**
- 在归墟内吸收精炼的能量，通过意识通道回传肉体
- 改造作用于肉体本身：肉体增强、血脉激活、血脉提升

### 回到现实后

- **神（意识）的增长会带回来**——这是永久性的
- **归墟连接会一直残留**，只是很微弱
- 通过残留连接，现实中也能从归墟获取少量能量
- **神强大后，可以直接从所在星球吸收能量**——不依赖归墟
- 能量吸收进肉体，一步步改造自身，提升战斗力

### 完整闭环

```
归墟内修炼 → 神增长（带回现实）
                ↓
        现实中吸收能量的能力提升
                ↓
    残留连接吸收归墟能量 + 神强了直接吸收星球能量
                ↓
        能量改造肉体 → 体扩容、气增加
                ↓
            战斗力提升
```

## 三重九阶

阶位按**气**（能量）划分，因为气决定等级与战斗力。

整体是三层嵌套：

```
三重 → 九阶 → 每阶三层（初 / 中 / 满）
```

- **体系名**：三重九阶
- **三重**：第一重、第二重、第三重
- **九阶**：一阶到九阶
- **每阶三层**：初、中、满

### 阶位与地域

阶位是全宇宙统一的能量量级度量，但不同区域能达到的上限不同：

| 区域 | 阶位范围 | 原因 |
|---|---|---|
| 东南西北四块基础大陆（含边缘与内部） | **一至九阶，九阶为极限** | 没有浓缩晶体 |
| 中心大陆 | 九阶之上 | 有浓缩晶体 |
| 低等宇宙的尽头 | 最高 | — |

- **九阶是四块基础大陆的硬上限**，无论边缘小块还是大陆内部，都突破不了
- 原因：突破九阶需要**浓缩晶体**——高等宇宙能量在归墟里被界晶浓缩后形成的晶体
- 注意：**浓缩晶体不是界晶本身**。界晶是原料，浓缩晶体是产物
- 四块基础大陆没有这种晶体，所以卡在九阶
- 晶体只产在中心大陆，想往上走，只能去中心大陆
- 更高层级属于后续剧情，第一部不展开

### 九阶与质变

| 重 | 阶 | 质变 |
|---|---|---|
| 第一重 | 一阶 感知 | 第一次沟通归墟，拿到能量 |
| | 二阶 内转 | 能量在体内循环，持续淬炼肉体 |
| | 三阶 筑体 | 肉体淬炼到位，容器第一次扩容 |
| 第二重 | 四阶 外放 | 能量反哺意识，意识开始增强 |
| | 五阶 凝形 | 意识能隔空作用于外物 |
| | 六阶 御物 | 隔空能力成熟，不靠肉体也能做很多事 |
| 第三重 | 七阶 场域 | 形成领域，产生威压；无领域者实力被全面削弱 |
| | 八阶 法域 | 领域内不再只靠自身，能直接调用宇宙能量 |
| | 九阶 天域 | 领域内敛，自身即领域；常驻防护、吸收与释放能量；初步触及归墟规则；低级宇宙的顶点 |

### 结构说明

- 共 27 个成长节点，日常只报"第几阶"
- 初、中、满三层用于体现同一阶内的进度差距，不单独命名
- 每一阶必须是质变，不是数值堆叠
- 三重名已定：第一重、第二重、第三重
- **九阶的名称仍是临时占位，待议**
- 三重的主导：第一重是**体**（淬炼容器），第二重是**神**（意识外化），第三重是**域**（形成领域→融合）
- 第二重的本质不是"能量离开身体"，而是"意识能隔空做事，不再依靠肉体"

### 瓶颈机制

- 每一阶内部（初→中→满）：靠能量的积累
- 跨阶、跨重：需要体先扩容到装得下下一阶段的能量
- 三元在等级体系里各有用处，不会退化成只练能量一个维度

### 可扩展性

- 阶位没有绝对上限，往上加阶不影响前九阶
- 扩展方式是换区域：四块基础大陆（九阶封顶）→ 北半球中心大陆 → 南半球中心大陆 → 低等宇宙的尽头
- 每一重只固定质变主题，不固定具体能力细节，后续补重不与前文冲突

## 命名的由来

### 曾经的讨论：精气神

**对应关系：**

| 三元 | 传统叫法 | 出处 |
|---|---|---|
| 神（控制器） | 神 | 神者，生之制也 |
| 体（承载） | 精 | 夫精者，身之本也 |
| 气（输出） | 气 | 气者，生之充也 |

- 出处：《黄帝内经·素问》、道家内丹学，人之三宝
- 内丹学有"炼精化气、炼气化神"的次第，可与修炼循环对应
- 顺序问题：传统是精→气→神（从下往上修），归墟的循环是神先行（从上往下带）。可以反用，形成"神驭精气"的新鲜感

**用户意见：**
- 精气神的思路可以（简单、有出处、读者零门槛）
- 但想换一个名字
- 倾向简单，不想特别特立独行

### 最终定名

**三个维度：神、体、气；整体称"三元"。**

- 神 = 意识、精神（控制器）
- 体 = 肉身、容器（承载）
- 气 = 能量、燃料（输出）

命名理由：都是最常用的字，读者零门槛，不需要额外解释，也不特立独行。神、气沿用传统说法，体用白话，整个体系一眼能懂。
