# 修炼资源体系调研

> 调研范围：斗破苍穹、遮天、完美世界（辰东小说）
> 目的：为归墟修炼资源体系设计提供参考
> 更新时间：2026-11-13

---

## 一、斗破苍穹：资源体系

### 丹药（核心修炼资源，共十品）

| 品阶 | 外显现象 | 功能 | 对应境界 |
|---|---|---|---|
| 一至三品 | 无明显现象 | 疗伤/回气/微弱提升 | 斗者～大斗师 |
| 四品 | 药香四溢，能量波动 | 辅助提升 | 斗灵 |
| 五品 | 能量涟漪 | 明显提升 | 斗王 |
| 六品 | 引发天地异象 | 强力提升 | 斗皇～斗宗 |
| 七品 | 招来丹雷，丹药具灵智会逃跑 | 重要分水岭 | 斗宗～斗尊 |
| 八品 | 灵智强，丹雷2–9色定品质 | 顶级资源 | 斗尊～半圣 |
| 九品 | 灵智堪比人类 | 极稀有 | 斗圣 |
| 帝品 | 传说级，含源气 | 助人成斗帝 | 斗帝 |

### 草药分级
- 一至十品，与丹药品阶直接对应
- **核心规律：品阶=产地危险程度**，高品草药几乎都在高阶魔兽栖息地或古迹禁区

### 魔核（魔晶）
- 魔兽体内凝聚的能量结晶，分一阶至十阶
- 阶数与魔兽战力对应，炼药主材
- 能量狂暴，不可直接吸收，只能用作炼丹材料或镶嵌武器

### 异火（特殊火焰资源，共23种）
- 斗气火（最弱）→ 兽火（中等）→ 异火（最强，有排行榜）
- 七品以上丹药需榜前列异火

### 炼药师品级与境界对应

| 炼药师品级 | 所需修为 | 灵魂境界 |
|---|---|---|
| 1–3品 | 斗者～大斗师 | — |
| 4–5品 | 斗灵～斗王 | — |
| 6–7品 | 斗皇～斗宗 | — |
| 8品 | 斗尊 | 灵境 |
| 9品 | 斗圣 | 天境 |
| 帝品 | 斗帝 | 帝境 |

### 资源获取场景
- **魔兽山脉**：野外采集草药、击杀魔兽获魔核，最基础
- **拍卖行**：高品丹药、稀有异火的流通市场
- **秘境/古迹**：古帝洞府、天焚炼气塔地底、造化圣者遗迹
- **门派传承**：各圣地、古族内部积累，不对外流通

## 二、遮天：资源体系

### 源（核心流通资源，共四级）

| 等级 | 形态/特征 | 价值/用途 |
|---|---|---|
| 普通源/纯净源 | 琥珀状晶体，蕴含天地精气 | 基础修炼、交易计价单位 |
| 异种源 | 变色变质的稀有源 | 以斤纯净源计价，价值数十至数千斤 |
| 神源 | 金/琥珀色晶体，能量极纯 | 封印古皇/圣人/太古生物；圣地间战略储备 |
| 仙源 | 近传说级，极稀有 | 封印大帝/至尊；仙帝级炼制 |

**资源数量级举例：**
- 道宫点亮一重天：需数万斤纯净源
- 道宫五重天：需百万斤源
- 四极秘境大圆满：需千万斤源

### 仙金（炼器顶级材料）
七种传世仙金：道劫黄金、龙纹黑金、羽化青金、神痕紫金、永恒蓝金、仙泪绿金、凰血赤金

### 资源获取场景

| 场景 | 说明 |
|---|---|
| 赌石坊 | 石皮包裹源，靠源术识别；高风险高回报，可开出神源甚至封印生物 |
| 源矿/矿区 | 各势力争夺，需挖掘采集 |
| 太初古矿 | 七大生命禁区之一，内藏大量未开采神源；但封印有九位以上至尊，极凶险 |
| 源天师一脉 | 通过源天书定龙脉、辨石识源，是系统获取高品源的核心技能树 |

## 三、完美世界（辰东）：资源体系

### 合道种子（最高端修炼资源）

**普通道种**（人道领域适用）：
魂力种子、血道种子、时间种子、五行种子

**仙种**（仙道领域适用，极稀有）：
世界树幼苗、鸿蒙紫气种、阴阳仙种、五行仙种、万道树、五魔封天种等

### 灵株秘药

**修行异种**（服用后改变根骨/血脉）：
混沌青莲、不死蟠桃药、太阳神藤等

**奇草灵药**（疗伤/增益类）：
仙桃树、通灵花、星辰草、血芝等

**顶级药物**：
三生药（起死回生）、帝丹（准仙帝级伤势可快速恢复）

### 资源与境界对应

| 资源层级 | 对应境界 |
|---|---|
| 普通灵药/奇草 | 人道中低境（搬血～神火） |
| 高阶灵株/坟中大药 | 人道高境（真神～至尊） |
| 仙药/帝丹 | 仙道境（真仙～准仙帝） |
| 合道仙种 | 仙道核心晋升资源 |

### 资源获取场景
- **界坟**：五行大陆，出产五行仙种等顶级仙种，极险之地
- **三千道州仙古遗地**：世界树幼苗等稀世仙种产地
- **坟中**（神秘古坟）：三生药等顶级大药产地，恐怖程度最高

## 四、横向对比

| 维度 | 斗破苍穹 | 遮天 | 完美世界 |
|---|---|---|---|
| 分级方式 | 品（1–10品，含帝品） | 按质地命名（普通→异种→神→仙） | 按来源/层级命名，无统一品阶 |
| 核心硬通货 | 丹药+魔核 | 源（以斤计量） | 合道种子+仙药 |
| 资源体系复杂度 | 最系统，与境界严格对应 | 中等，源术为核心技能树 | 最分散，无统一分级表 |
| 主要获取场景 | 魔兽山脉+拍卖行+古迹秘境 | 赌石坊+源矿+生命禁区 | 界坟+仙古遗地+古战场 |
| 顶级资源稀缺性 | 帝品丹药唯一（古帝洞府） | 仙源近传说级 | 仙种绝大多数唯一 |

## 五、对归墟资源体系的设计启示

**可以借鉴的点：**
- 斗破的"品阶=产地危险程度"：归墟的资源越往中心走越高级，天然契合大陆格局
- 遮天的"源以斤计量"：有量化感，日常交易有质感，不抽象
- 斗破的"丹药系统化"：资源和境界严格对应，读者清晰，写作方便

**归墟特有的设计方向：**
- 能量本身（无论叫什么名字）可以凝结成晶体形态，分级流通——类似遮天的"源"
- 浓缩晶体已定为突破九阶的顶级资源，往下可以设计普通晶体（一至九阶对应）
- 归墟内各大陆危险程度不同，资源品质天然分层：边缘小块（低品）→ 大陆内部（中品）→ 中心大陆（高品）
