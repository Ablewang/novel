# 势力格局设计调研

> 调研范围：斗破苍穹、完美世界（辰东小说）、遮天
> 目的：为归墟内部势力格局设计提供参考
> 更新时间：2026-11-13

---

## 一、斗破苍穹势力格局

### 地域层级（由低到高）
- **外域各地区**：按方位分为西北、东北、东南等，每个地域有若干帝国，战力天花板低
- **中州**：大陆核心，强者云集，斗皇只能勉强立足，斗尊以上才有话语权
- **远古八族独立空间**：如古界、魂界，能量浓度最高，斗圣的真正摇篮

### 势力分类

| 类型 | 代表 | 特征 |
|---|---|---|
| 帝国+家族 | 加玛帝国、萧家、云岚宗 | 外域基本单元，皇室+世家+宗门 |
| 中州宗门/谷/阁 | 花宗、焚炎谷、风雷阁 | 单一功法/资源方向专精，独立于帝国之外 |
| 超级机构 | 丹塔、炼药师公会 | 职能型，服务全大陆，不直接称霸 |
| 黑恶势力 | 黑角域各势力、血宗 | 无政府区，靠实力自保 |
| 隐秘古族 | 远古八族（魂族/古族/萧族等） | 拥有斗帝血脉，外界不知其存在 |

### 势力层级（中州明面）
"一殿一塔二宗三谷四方阁"：
- **顶级**：魂殿（+魂族背景）、丹塔
- **中级**：花宗、天冥宗；焚炎谷、冰河谷、音谷
- **下级**：星陨阁、风雷阁、万剑阁、黄泉阁
- **凌驾一切（隐藏）**：远古八族

### 新人进入体系的方式
- **学院入学**：迦南学院，测斗之气星级 → 实战展示 → 长老认可
- **宗门直接招募**：有修炼天赋者投奔，大宗门有门槛要求
- **炼药师行会**：按品阶认证，需同级炼药师联名推荐
- **家族传承**：古族等严格血脉限制

### 势力关系模式
- 中州宗门之间以利益联盟为主，明争暗斗，魂殿是共同敌人
- 外域帝国与中州宗门层级不对等，外域强者须亲赴中州方能进入更高体系
- 远古八族与中州势力之间存在信息不对等壁垒

## 二、完美世界（辰东）势力格局

### 势力分类

| 类型 | 代表 | 特征 |
|---|---|---|
| 超级书院（教育型） | 天神书院、圣院、仙院 | 专门培养对抗异域战力，不为自身利益 |
| 长生世家 | 王家、金家、风族、徐家 | 祖上出过真仙境强者，底蕴深厚 |
| 三千道州道统 | 仙殿、剑谷、妖龙道门 | 地方性宗门 |
| 禁区 | 五个有仙王坐镇的禁区 | 超然世外，不参与常规竞争 |
| 仙古遗族 | 蓝金岭、堕神岭、人马族 | 仙古纪元遗留，非主流体系 |

### 势力层级
- **最高层（隐藏）**：禁区，仙王境坐镇
- **顶级**：三大书院；长生世家头部（王家、金家）
- **中级**：五大残仙道统；一般长生世家
- **基础层**：三千道州的普通道统/宗门

### 新人进入体系的方式
- **书院选拔**：通过无人区试炼，或在帝关服役守卫，以实战表现获得名额
- **击败在读弟子**：石昊通过击败天神书院弟子获得入学名额
- **大长老特招**：大长老亲自考察后收入门下
- **长生世家**：血脉传承，出身即决定归属

### 势力关系模式
- **内部分裂**：长生世家中部分通敌异域，部分坚守抵抗——叛徒与忠诚者的对立
- **资源不公**：书院资源向大家族倾斜，普通弟子处于系统性弱势
- **书院与道统并行**：书院面向全九天十地，道统各守一方

## 三、遮天（辰东）势力格局

### 势力分类

| 类型 | 代表 | 特征 |
|---|---|---|
| 荒古世家 | 姬家、姜家（瑶池圣地） | 大帝开创，有帝兵+大帝阵纹+神源液 |
| 圣地 | 摇光圣地、紫府等 | 大圣开创，标配传世圣兵 |
| 皇朝 | 中州四大皇朝 | 政治型势力，兼具军事与修炼 |
| 超级大教 | 太玄门、逍遥门 | 低于圣地，开创者未必成圣 |
| 小型洞天 | 灵墟、金霞等六大洞天 | 附属于圣地，输送人才 |
| 生命禁区 | 荒古禁地、太初古矿等 | 超然一切势力，不可正面对抗 |

### 势力层级（五层）
1. **禁区**：七大生命禁区，仙王/准帝级存在
2. **T1**：姬家、姜家/瑶池、中州四大皇朝——大帝传承+帝兵
3. **T2**：摇光圣地等——有帝兵无大帝神源液
4. **T3**：紫府、道一等标准圣地——大圣开创+传世圣兵
5. **T4及以下**：太玄门/逍遥门 → 六大洞天

### 新人进入体系的方式
- **洞天向圣地输送**：小派弟子通过圣地派遣长老的考核（修为+资质），通过后升级为圣地弟子
- **特殊体质特招**：先天道胎、圣体等特殊资质，圣地主动特招
- **大佬担保/推荐**：有强者引荐可绕过常规考核
- **圣子/圣女制度**：内部竞争晋升为圣地代言人，享有最高资源倾斜

### 势力关系模式
- **圣地间以源矿资源争夺为核心矛盾**
- **附属关系链**：禁区 → 荒古世家/顶级圣地 → 普通圣地 → 大教 → 洞天小派
- **人族与妖族对立**：非灭族性对立，长期摩擦
- **禁区独立于一切**：超然所有阵营

## 四、横向对比

| 维度 | 斗破苍穹 | 完美世界 | 遮天 |
|---|---|---|---|
| 核心势力单元 | 宗门/古族/机构 | 书院/世家/道统 | 圣地/荒古世家/皇朝 |
| 层级数量 | 3层 | 4层 | 5层 |
| 新人入门主渠道 | 学院考试、宗门招募 | 危险试炼、书院选拔 | 小派输送+考核、特殊体质特招 |
| 顶级势力可见度 | 低（古族对外隐藏） | 中（书院公开，禁区隐藏） | 低（禁区超然，荒古世家半隐） |
| 势力间主要矛盾 | 资源+血脉仇恨+幕后黑手 | 外敌压力下的内部叛徒问题 | 资源（源矿）争夺+体制内竞争 |
| 中间组织特色 | 炼药师公会（职能型跨势力机构） | 无中立中间机构 | 源城（中立交易城市） |

## 五、对归墟势力格局的设计启示

**可以借鉴的点：**
- 遮天的"小派输送"机制：蓝星新人进入归墟后，先在边缘小块的小势力立足，再逐步进入更大体系
- 斗破的"职能型机构"：归墟内可以有类似丹塔的中立机构（如交易所、信息站），服务全归墟
- 完美世界的"内部叛徒"：归墟内部势力可以有通敌/背叛的隐线，增加复杂度

**归墟特有的设定优势：**
- 归墟已运行一亿年，原住民势力极为古老，蓝星人是绝对的新人——天然的信息不对等
- 各宇宙文明都在同一个归墟内，势力构成比单一大陆更多元
- 四大基础大陆九阶封顶，所有势力在同一天花板下竞争，格局更稳定
