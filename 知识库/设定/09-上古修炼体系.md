# 上古修炼体系

## 核心设定

上古时期高等文明统治蓝星时，留下了一套完整的能量修炼体系，帮助低等文明的人类更好地吸收界晶能量。大洪水（高等文明撤走的副产物）摧毁了这套体系，各文明只保留了残片。

各地的修炼传统——中国道家、印度瑜伽、西藏密宗、北欧魔法、埃及祭司术——本质上是同一套体系的不同残片，方向各有侧重，但底层逻辑完全相通。

归墟出现（2029年）后，逸散能量开始充斥蓝星，这些残片被重新激活——那些坚持传统修炼的人，率先感受到了变化。

## 统一底层逻辑

所有体系的表述，都是同一套东西的不同语言：

| 各文明叫法 | 统一本质 |
|--------|--------|
| 气/普拉纳/拙火/赫卡/萨兹/Orenda | 人体吸收归墟逸散能量后的内在形态 |
| 经络/脉道/脉轮/生命之树 | 人体内的能量通道网络 |
| 内丹/虹光身/三摩地/与神合一 | 意识与归墟深度连接后的不同文明表述 |
| 修炼/苦行/禁食/自我牺牲 | 强迫身体进入极限状态以打通能量通道 |
| 圣地/能量节点/地脉/瓦卡 | 福地——逸散能量在此汇聚 |
| 神通/悉地/卡拉马特/验 | 能量等级提升后对外的能力表现 |

## 为什么中国保留最完整

道家体系最接近完整的原因：
- 地处昆仑-峨眉-武当的能量干线，修炼者长期处于微弱能量环境，反馈更真实
- 文化连续性最强，口传体系保存时间最长
- 内丹学明确分出"炼精化气→炼气化神→炼神还虚"三个阶段，与归墟连接的三个深度高度吻合
- 但仍是残片：飞升功法失传，只剩前段的能量积累部分

## 归墟出现后的变化（2029年~）

归墟逸散能量开始充斥蓝星后，传统修炼者最先感受到变化：

- **道家/佛家修行者**：静坐时突然感到能量涌入，以为是"功夫到了"
- **印度瑜伽士**：昆达利尼莫名上升，有人发生意外（能量冲顶但身体未准备好）
- **西藏密宗修行者**：拙火修炼效果急剧增强，部分人身体温度异常
- **北美萨满**：出体频率提升，但灵界景象开始出现"陌生建筑"（归墟外围）
- **苏菲修行者**：齐克尔中达到法纳状态的速度变快

这些现象在2029~2035年间被各地研究机构记录，成为归墟研究的早期线索之一。

## 上古修炼体系的觉醒机制（待完善）

部分人在归墟内成长后，会在梦中出现"残片记忆"——不是他们自己的记忆，而是上古时期修炼体系的片段。

这可能的解释：
- 归墟记录了蓝星所有文明的能量信息，包括上古的完整修炼体系
- 修炼者在归墟内连接深度达到某个阈值后，开始接触到这些记录
- 不同血统的人接触到的残片不同（中国人梦到内丹路径，印度人梦到脉轮图）

**这是上古修炼体系重新被人类发现的路径，也是故事中期的重要线索。**
