## 一、归墟的真实运作逻辑

归墟不是制造新能量，是一个**能量精炼中转站**：

1. 自然状态下高等宇宙能量会补充到全宇宙，归墟将这部分能量集中起来
2. 全宇宙的生物降临归墟，通过归墟完成低等宇宙能量的压缩和精炼
3. 归墟拿精炼后的低等宇宙能量与高等宇宙能量做交换
4. 整体流程是自然的能量循环，没有任何异常数据，混沌族感知不到任何可疑信号

**需要更新的文档：** `01-核心规则.md`、`05-归墟.md`

## 二、主宰血脉的能量转换机制

- 只有**高等宇宙能量**才能被主宰血脉转换成第二层宇宙能量
- 苏木觉醒前只接触过低等宇宙能量，无法触发转换
- 通天塔检测用的是归墟里的高等宇宙能量——苏木第一次接触高等宇宙能量
- 主宰血脉自动将高等宇宙能量转换成第二层宇宙能量
- 神器吸收第二层宇宙能量后激活

## 十六、三重九阶（已定名）

**三层嵌套：**

```
三重 → 九阶 → 每阶三层（初 / 中 / 满）
```

- 体系名：**三重九阶**
- 三重：第一重、第二重、第三重
- 九阶：一阶到九阶
- 每阶三层：初、中、满

**阶位与地域（重要：可扩展的核心）**

大陆层级（本轮更正）：
- 北半球：东南西北四个**基础大陆** + 中间一块**北半球中心大陆**
- 南半球：极南一块**中心大陆**
- 每块基础大陆内部切分成多个小块
- 蓝星落在四块基础大陆之一，且只是那块大陆的**边缘小块**

力量上限：
- **四块基础大陆统一九阶封顶**——边缘小块和大陆内部都一样
- 原因：突破九阶需要**浓缩晶体**——高等宇宙能量在归墟里被界晶浓缩后形成的晶体
- **不是界晶本身**：界晶是原料，浓缩晶体是产物
- 四块基础大陆没有浓缩晶体，所以卡在九阶
- 往上之路：四块基础大陆（九阶封顶）→ 中心大陆 → 低等宇宙的尽头
- 往上加阶不影响前九阶，前面不用改

中心大陆地底（本轮新增）：
- 中心大陆最中间地底有一个**器灵开辟的小世界**
- 小世界里有一块**银河系大小的界晶**
- 作用是控制高等宇宙能量集中在中心，浓缩成晶体
- 这是各势力死磕中心的真实动机
- **只有身怀太初晶的人能进小世界，也就是只有苏木**
- **进入需要极强体魄**，体不够进不去——器灵留给苏木的门，也是资源门槛
- 其他势力只能在中心大陆外围争夺散落的晶体

**待确认：** 银河系大小的界晶在哪块中心大陆（北半球 / 南半球 / 各有一块）、体魄门槛对应第几阶

**九阶与质变：**

| 重 | 阶 | 质变 |
|---|---|---|
| 第一重 | 一阶 感知 | 第一次沟通归墟，拿到能量 |
| | 二阶 内转 | 能量在体内循环，持续淬炼肉体 |
| | 三阶 筑体 | 肉体淬炼到位，容器第一次扩容 |
| 第二重 | 四阶 外放 | 能量反哺意识，意识开始增强 |
| | 五阶 凝形 | 意识能隔空作用于外物 |
| | 六阶 御物 | 隔空能力成熟，不靠肉体也能做很多事 |
| 第三重 | 七阶 场域 | 形成领域，产生威压；无领域者实力全面削弱 |
| | 八阶 法域 | 领域内不再只靠自身，能直接调用宇宙能量 |
| | 九阶 天域 | 领域内敛，自身即领域；常驻防护、吸收与释放能量；初步触及归墟规则；低级宇宙的顶点 |

**修炼底层逻辑（本轮澄清）：**

- 本质是**能量**，不是传统意义上的"气"
- 意识沟通归墟 → 获取宇宙能量 → 能量淬炼肉体
- 肉体强了 → 反哺意识 → 意识强了能隔空做事
- 但意识需要肉体当容器，二者相辅相成
- 二者相辅相成到一定程度 → 形成领域
- 领域完美 → 二者融合 → 九阶
- 九阶用的是低级宇宙能量，所以只能到低级宇宙的顶点

**三重的主导：**
- 第一重：**体**（淬炼容器）
- 第二重：**神**（意识外化，隔空做事，本质不是能量离体）
- 第三重：**域**（领域 → 融合）

**七到九阶的细化：**
- 七阶：形成领域，产生威压，对无领域者实力全面削弱
- 八阶：领域内不再只靠自身，能调用宇宙能量
- 九阶：领域内敛，自身即领域；常驻防护、吸收与释放能量；初步触及归墟规则

**命名过程：**
- 用户不喜欢"境界"这个总称
- 不用"九重"这个叫法，认为"九阶"好
- 三大块最初想叫"段/块"，用户嫌难听
- 用户给出方向：类似"三重九阶、三等九阶"的结构
- 比较后选"三重九阶"："三重"有古韵，日常说法也顺
- 总称保留"阶位"

**已定：** 体系名"三重九阶"、三重名、九阶单位、初/中/满
**待议：** 九阶的正式名称

## 十七、九阶命名方案：A 成组 vs B 成画

### 问题诊断：为什么之前的名字"乱"

试过且被否掉的方案：

- 初/中/满 → 俗套、不好听
- 微候/盛候/极候 → 不行
- 始/盛/圆、缕/股/泓、泉/江/海 → 难听
- 气感/行气/炼体/外发/凝真/役物 → 太绕口
- 感气/行气/炼体/外放/成形/御物 → 太普通
- 感通/周流/炼形/离形/成器/御物 → 不如"引气周天易筋离体化形御物"，而这些都烂大街
- 纳元/周流/成器/养神/出神/乘物/立域/通域/合域 → 有感觉，但乱

**"乱"的根因：对象一直在换。**

纳元（对象是能量）→ 周流（还是能量）→ 成器（对象变成肉体）→ 养神、出神（对象变成意识）→ 乘物（对象变成外物）→ 立域/通域/合域（对象变成领域）。

主流体系是"同一个东西一路往上长"（斗者、斗师、斗王），我们是"五个东西轮流登场"，读者刚记住一个，下一阶就换了。

### 两条路线

**A. 每重用同一个字根**（像斗者、斗师、斗王那样一眼成组）

| 重 | 阶 | 名字 | 质变 |
|---|---|---|---|
| 第一重（体） | 一阶 | **感体** | 第一次感觉到体内的能量 |
| | 二阶 | **行体** | 能量在体内循环，持续淬炼 |
| | 三阶 | **铸体** | 肉体炼成容器，第一次扩容 |
| 第二重（神） | 四阶 | **凝神** | 能量反哺意识，意识凝聚增强 |
| | 五阶 | **出神** | 意识能出体，隔空作用于外物 |
| | 六阶 | **御神** | 隔空能力成熟，神能驭物 |
| 第三重（域） | 七阶 | **立域** | 形成领域，威压削弱无领域者 |
| | 八阶 | **通域** | 领域内直接调用宇宙能量 |
| | 九阶 | **合域** | 自身即领域，人域合一 |

字根：体、神、域。日常可说"他在第三重的御神阶"。
代价：**御神** 最生硬，"御"作前缀别扭；**铸体** 偏硬。其余七个站得住。

**B. 全部改成结果名**（像金丹、元婴那样，每阶一个名词，读者只记结果）

| 阶 | 名字 | 多了什么 |
|---|---|---|
| 一阶 | **元种** | 一缕能量种进体内，第一次接通归墟 |
| 二阶 | **周流** | 能量自成循环，日夜不息地淬炼肉身 |
| 三阶 | **玉骨** | 肉身脱胎换骨，容器第一次扩容 |
| 四阶 | **灵台** | 意识凝成一座台，不再散乱 |
| 五阶 | **神游** | 意识能离体，隔空触碰外物 |
| 六阶 | **神胎** | 意识长成独立的"另一个自己"，不靠肉体也能办事 |
| 七阶 | **法域** | 撑开一片域，域内你说了算，无域者被全面压制 |
| 八阶 | **天域** | 域内可直接借宇宙之力 |
| 九阶 | **归一** | 人域合一，自身即域 |

连起来：元种 → 周流 → 玉骨 → 灵台 → 神游 → 神胎 → 法域 → 天域 → 归一

取词点：
- **灵台**：《庄子》"灵台者有持"，指心、指意识，对应四阶意识凝实，不是网文烂词
- **神胎**：借内丹"阳神"意象，避开"阳神"本身，对应六阶意识独立成形
- **法域/天域/归一**：域的三种状态——有域 → 域可借力 → 人域合一

代价：
- 前后风格天然断层：前六阶是"体内多出来的东西"，后三阶回到"域"字辈，读起来会跳（但这一跳落在第三重质变上，不算硬伤）
- 每阶都要读者新记一个词，不像 A 记住三个字根就能推全表
- **元种、神胎** 最"造"，**玉骨** 偏清冷，可能不合"体"的厚重感

### 两方案对比

| | A 成组 | B 成画 |
|---|---|---|
| 记忆方式 | 记字根，推全表 | 每阶记一个意象 |
| 整齐度 | 高 | 前六后三断层 |
| 画面感 | 弱（动作名） | 强（结果名） |
| 生硬处 | 御神、铸体 | 元种、神胎、玉骨 |
| 写作便利 | 报阶顺口 | 每阶有具体物象可写 |

## 十八、能量命名：卡住了

### 核心发现

九阶等级名的前提是：**先确定能量叫什么**，等级名从能量名派生。

逻辑参考：斗气大陆能量叫"斗气" → 等级是"斗者、斗师、斗王"；修仙能量叫"灵气" → 等级是"炼气、筑基、金丹"。

### 能量的基本设定

- 本质：从高等宇宙流入低等宇宙的宇宙能量
- 被归墟汇聚，生物吸收后淬炼自身
- 第一次感知：身心舒畅，充满力量
- 格调要求：神秘、幽深、厚重、古朴
- 字数：两个字

### 试过且被否掉的方向

**从意象找（字典排列组合）：**
- 冥力、渊力、苍力、玄力、晦力 → "跟能量有啥关系"
- 湛华、浩息、渊华、冥华、昊华 → 没感觉
- 29×18 组合表（见`设定/草稿/能量命名候选.md`）→ 没有特别喜欢的

**从"来处"找：**
- 膏泽、醴流、沆瀣 → "完全不对"

**直白路线：**
- 源能、灵能、灵气 → 用户自己想到的，但觉得烂大街
- 苍气/能/力、穹气/能/力、冥气/能/力等 → 都差点意思
- 归力、墟力、墟气、归气 → 没感觉

**双字叠意：**
- 冥渊、苍冥、太虚、混冥、渊冥、穹冥 → "不像可吸收的能量"

**有一点感觉但不够：**
- **玄灵**：有古朴感，但说不清哪里差一点

### 卡住的根本原因

后缀问题：气/能/力太普通，其他后缀又不像"可吸收、可流动、在体内运行"的东西。需要一个**既不烂大街、又有流动充盈感**的后缀，目前没找到。

### 下次继续方向

- 能量的颜色（未定，可以从这里切入）
- 或者直接造词，不拘泥于现成字
- 保留"玄灵"的调性感，往周围继续磨

## 十九、能量命名：新进展

### 新增设定（本轮确认）

- **转化过程辛苦**：大量吸收转化时，是在逼迫肉体改变，不是温柔滋养
- **第一次感知"身心舒畅"**是因为量极少，真正修炼是磨砺
- 能量气质：**磨砺、锻造、逼迫改变**，不是灵气那种温润滋养
- 这解释了为什么修炼有门槛：体不够强装不下，神不够强控制不住

### 对命名的影响

能量不是"柔和滋养型"，而是**有强度、有侵略性、锤炼型**的。

这把"灵气、灵力"这类温润感的词彻底排除——那个感觉不对。

### 大方向（本轮确认）

- 故事类型：**宇宙流玄幻**
- 参考调性：遮天/完美世界的恢弘大气 + 斗气大陆的通俗易懂朗朗上口
- 能量本质意象：**天地本身的一部分，吸收它就是在把自己变成天地**
- 转化过程：辛苦、磨砺、锻造

### 试过且被否掉（本轮新增）

- 乾元、坤元、元炁、太元、玄元、混元、乾炁、化元、天元 → 太古板不顺口
- 天力/气、苍力/气、穹力/气、冥力/气、渊力/气等大批组合 → 没感觉
- 原息/脉/华/泽/炁、天原/苍原/冥原等 → 没感觉
- 凌气/力等 → 越来越远

### 当前状态

- 能量命名**仍未定**
- 新约束：名字不能有"温润柔和"的感觉，要有强度和厚重感
- 名字必须同时满足：**可吸收、可在体内流动、有强度、不柔和**
- 试过"劲、威、煞、罡"→ 偏外放，不像能吸收的东西
- 试过酒/火意象（烈气、炽气、熔气等）→ 都不行
- 继续讨论中

## 二十、能量命名：新物理概念切入

### 新增设定（本轮确认）

- 宇宙能量的现代物理对应：**暗物质/暗能量**
  - 看不见、测不到
  - 隐藏在可见宇宙背后
  - 无质量无形态，纯粹的能量
- **阴阳框架**：阳 = 现实空间（可见有形），阴 = 暗能量（隐藏无形）
- **宇宙背景辐射**：大爆炸留下的余晖，无处不在，是宇宙最底层的背景能量

### 本轮试过且被否掉

- 暗能 → 有点感觉，但不够创新，拗口（两字都是降调）
- 暗力/暗气/暗流/暗涌等 → 没感觉
- 隐/冥/晦/幽/玄/微/昧/潜/伏/虚/空/寂等字 → 没感觉
- 阴能/阴力/玄阴/太阴/真阴 → 负面联想太强或不对
- 素能/朴能/一气等"道家本原"方向 → 不行

### 卡住的本质

用户对"暗能"有一点感觉，说明**"暗"的方向是对的**，但这个词不够创新且拗口。需要找一个：
- 有"暗/隐藏/宇宙背后"的意象
- 读起来顺口
- 有创意，不是直白拼接
- 像个能被人体吸收的能量名称
