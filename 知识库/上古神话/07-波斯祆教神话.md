# 波斯/祆教神话体系（琐罗亚斯德教）

---

## 一、重要文献

### 1. 《阿维斯塔》（Avesta）
- **年代**：约公元前1500—600年（口传），公元3—7世纪成文
- **内容**：祆教圣典，包含《伽萨》（琐罗亚斯德亲作的17首颂诗）、《雅斯纳》（礼拜仪式）、《亚什特》（神灵颂歌）等
- **重要段落**（《伽萨》，雅斯纳30章，善恶二元论）：
  > "确实，太初之时有两个精神，它们是双胞胎，却在思想、言语和行动上相互对立——善与恶。在它们之间，智慧者做出正确的选择，而愚昧者则不能。当这两个精神相遇时，他们创造了生命与非生命……"

### 2. 《布达希什尼》（Bundahishn）
- **年代**：约9世纪（萨珊王朝后期波斯文）
- **内容**：创世神话、宇宙志、末世论的完整记载

### 3. 《沙赫纳梅》（Shahnameh，列王纪）
- **年代**：约公元1010年（菲尔多西著）
- **内容**：波斯最伟大的史诗，约5万双行，从神话时代到伊斯兰征服，包含大量古代神话英雄传说

## 二、宇宙创世

### 善恶二元论（祆教核心）

祆教宇宙观建立于两个永恒对立的原则：

- **阿胡拉·马兹达（Ahura Mazda）**："智慧之主"，光明、善、创造之神，至高存在
- **阿里曼（Angra Mainyu/Ahriman）**："邪恶精神"，黑暗、恶、破坏之源

最初，阿胡拉·马兹达独自存在于无限光明，阿里曼独自存在于无限黑暗，二者之间是虚空。

阿胡拉·马兹达用思想创造了理想的精神世界（**美诺克，Menog**），然后创造了物质世界（**格提克，Geti**）。

阿里曼入侵，污染了完美的创造：
- 将毒药注入植物
- 用蜥蜴污染水
- 将死亡带给第一个人
- 在每种善的创造中植入对应的恶

### 创世六日（Amesha Spentas，六大神圣不朽者）
阿胡拉·马兹达创造六个神圣助手，各主管一种创造：

| 名称 | 职司 | 守护的创造物 |
|------|------|-------------|
| **沃胡·马纳（Vohu Manah）** | 善的思想 | 有益动物 |
| **阿沙·瓦西什塔（Asha Vahishta）** | 真理/正义 | 火 |
| **沙赫里瓦尔（Khshathra Vairya）** | 好的统治 | 金属/天空 |
| **斯彭塔·阿玛提（Spenta Armaiti）** | 神圣虔诚 | 大地 |
| **豪尔瓦塔特（Haurvatat）** | 完整/健康 | 水 |
| **阿姆雷塔特（Ameretat）** | 不朽 | 植物 |

## 四、末世论（弗拉什科尔蒂，Frašō.kərəti）

祆教有世界上最完整的末世论之一，深刻影响了基督教、伊斯兰教的末日观：

### 宇宙时间
- 总共12000年宇宙时间，分四个3000年阶段
- 前3000年：纯精神世界
- 第二个3000年：物质世界创造，阿里曼入侵
- 第三个3000年：善恶交战，琐罗亚斯德降生传播教义
- **最后3000年**：三位救世主（Saoshyant）相继降生，最终审判

### 末日过程
1. 宇宙陷入极寒（类似北欧芬布尔之冬）
2. 恶魔与善神最终决战
3. 山岳融化，金属河流遍布大地——善人行走无感，恶人如同沸腾牛奶般痛苦
4. 死者全部复活（**弗拉沙格尔德**）
5. 最终审判，善人上天堂，恶人受苦后净化
6. 阿里曼被永久消灭，宇宙恢复最初的完美状态
7. **善的最终胜利**——这是祆教与其他神话末世论的根本区别
