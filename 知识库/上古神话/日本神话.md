# 日本神话体系（神道）

---

## 一、重要文献

### 1. 《古事记》（Kojiki）
- **年代**：712年（日本现存最古老的文献）
- **内容**：太安万侣编撰，记载神代（神的时代）、人代（人的时代）的历史与神话，三卷
- **重要段落**（创世开篇）：
  > "天地初发之时，于高天原成神名，天之御中主神。次，高御产巢日神。次，神产巢日神。此三柱神者，并独神成坐而，隐身也。"
- **重要段落**（伊邪那岐与伊邪那美造国）：
  > "于是天神诸命以，天沼矛赐而，言依赐也。故，二柱神立天浮桥而，指下其沼矛以画者，盐许许袁袁呂呂迩画鸣而，引上时，自其矛末垂落之盐，累积成岛，是淤能碁呂岛。"

### 2. 《日本书纪》（Nihon Shoki）
- **年代**：720年
- **内容**：舍人亲王编撰，更系统的正史，记载天地开辟至持统天皇时期，包含多个神话异传版本

## 二、宇宙创世

### 天地开辟
最初天地混沌，后轻清者上升为天（高天原），重浊者下降为地。**高天原（Takamagahara）**中依次生出独神（无性别）：

1. **天之御中主神（Amenominakanushi）**——宇宙中心之主
2. **高御产巢日神（Takamimusubi）**
3. **神产巢日神（Kamimusubi）**
4. **宇摩志阿斯诃备比古迟神（Umashiashikabihikoji）**
5. **天之常立神（Amenotokotachi）**

此五神称**造化三神/别天神**，造化完毕后隐身。

之后又生出七代神，最后一代为**伊邪那岐（Izanagi）**与**伊邪那美（Izanami）**。

### 国土创造
天神命伊邪那岐与伊邪那美站在**天浮桥（Ame-no-Ukihashi）**上，以**天沼矛（Ame-no-Nuboko）**搅拌混沌之海，矛端落下的盐堆积成第一座岛**淤能碁呂岛（Onogoro）**。二神下降，在岛上立神柱，绕柱相遇，结为夫妻，生下日本诸岛与众多神祇。

## 三、神祇谱系

### 创世主神
| 神名 | 职司 |
|------|------|
| **伊邪那岐（Izanagi）** | 男神，国土与众神之父 |
| **伊邪那美（Izanami）** | 女神，国土与众神之母，后成冥界女主 |

### 三贵子（最高神）
伊邪那岐从黄泉归来洁身时，从左眼、右眼、鼻子生出三神：
| 神名 | 职司 | 象征 |
|------|------|------|
| **天照大御神（Amaterasu）** | 太阳神、天界之主、皇室祖神 | 从左眼生，主管高天原 |
| **月读命（Tsukuyomi）** | 月神 | 从右眼生，后因杀死食物神被天照疏远（解释昼夜分离） |
| **须佐之男命（Susanoo）** | 风暴神、海洋 | 从鼻生，因哭泣思母被放逐 |

### 其他重要神祇
| 神名 | 职司 |
|------|------|
| **大国主命（Okuninushi）** | 国土建设、医药、农业、姻缘 |
| **事代主神（Kotoshironushi）** | 福神之一，鱼神 |
| **稻荷神（Inari）** | 农业、丰收、工商业，狐狸为使者 |
| **八幡神（Hachiman）** | 战神、弓箭，应神天皇神格化 |
| **天钿女命（Ame-no-Uzume）** | 舞蹈、艺术，令天照走出岩户的女神 |
| **建速须佐之男命** | 须佐之男命，杀八岐大蛇 |

## 四、重要神话故事

### 1. 黄泉之国
伊邪那美在生火神时灼伤而死，进入黄泉之国。伊邪那岐思念妻子，追入黄泉。伊邪那美嘱咐他不要看自己，但伊邪那岐忍不住，折下发间木梳点火，看见妻子身体已腐烂、蛆虫横生。伊邪那美大怒追杀，伊邪那岐逃出，用大石封住黄泉入口。两神从此分离，伊邪那美诅咒每日杀死千人，伊邪那岐誓言每日生出千五百人——生死平衡因此确立。

### 2. 天岩户（天照闭关）
须佐之男命因哭闹，被天神放逐，临行前去向姐姐天照辞别，引发天照猜疑，二人以"誓约"生子证清白。须佐之男命之后大肆破坏田地、污秽神殿，天照大御神受惊，躲入**天岩户（Ame-no-Iwato，天照洞）**，世界陷入黑暗，灾祸横生。

八百万神聚集，想出妙计：在洞前种树、挂镜与勾玉，**天钿女命**跳起粗野舞蹈，众神哄堂大笑。天照好奇开缝张望，一位神拉开巨石，**天手力男神**拉出天照，世界重现光明。**八尺镜（Yata no Kagami）**与**勾玉（Yasakani no Magatama）**从此成为皇室三神器之二（另一为草薙剑）。

### 3. 须佐之男命杀八岐大蛇（Yamata no Orochi）
被放逐的须佐之男命来到出云，见一对老夫妇哭泣——他们的七个女儿已被八头八尾大蛇吃掉，最后一个女儿奇稻田姬也要被吃。须佐之男命用八桶烈酒让大蛇喝醉，趁其熟睡斩杀，从蛇尾中发现神剑**天丛云剑（后称草薙剑，Kusanagi）**，献给天照。

### 4. 大国主命建国
须佐之男命后裔**大国主命**历经重重考验，建设苇原中国（日本人间），发展农业、医药、开创国土。后来天照派使者要求大国主命让渡国土，大国主命经过与儿子商议，同意将可见世界让给天孙，自己治理隐界（神界）——**国让（Kunitsukami）**。

## 五、日本神道宇宙观

### 三界结构
- **高天原（Takamagahara）**：天界，天照大御神统治
- **苇原中国（Ashihara no Nakatsukuni）**：人间，大国主命后让于天孙
- **黄泉之国（Yomi no Kuni）**：冥界，伊邪那美统治
- **根之堅州国（Ne no Katasukuní）**：须佐之男命统治的海底冥界

### 八百万神（Yaoyorozu no Kami）
日本神道认为世界万物皆有神灵——山有山神、河有河神、石有石神、灶有灶神……自然界的一切现象与事物均为神明，总数"八百万"象征无穷无尽。

### 天孙降临
天照大御神命孙子**邇邇芸命（Ninigi）**降临苇原中国统治，携带三神器（铜镜、勾玉、宝剑）——皇室权威的象征。邇邇芸命的曾孙即神武天皇，日本第一代天皇，皇室由此被认为是天照大御神的直系后裔。

## 六、宇宙观总结

```
混沌
└── 高天原（天界）自发生成
    └── 造化三神（独神）→伊邪那岐+伊邪那美
        └── 日本诸岛+众神
            ├── 天照（高天原）
            ├── 月读（隔离）
            └── 须佐之男（海/根国）
                └── 大国主命（人间）
                    └── 天孙降临→天皇→人类历史
```
