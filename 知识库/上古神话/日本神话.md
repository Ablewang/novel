# 日本神话体系（神道）

## 一、主要文献

### 《古事记》（Kojiki）
- **年代**：公元 712 年，日本最古老的文献
- **内容**：从创世到推古天皇时代的神话与历史
- **重要片段**：

> **《古事记》创世（节选）**
>
> *天地初发之时，高天原所成神名，天之御中主神。次，高御产巢日神。次，神产巢日神。此三柱神者，并独神成坐而，隐身也。*
>
> *次，国稚如浮脂而，久罗下那洲多陀用弊流之时，如苇牙因萌腾之物而成神名，宇摩志阿斯训备比古遅神。次，天之常立神。此二柱神，亦独神成坐而，隐身也。*

### 《日本书纪》（Nihon Shoki）
- **年代**：公元 720 年
- **内容**：与《古事记》并列的官方神话历史，采用中国编年史体例

### 《风土记》
- **年代**：公元 713 年起各地陆续编写
- **内容**：各地方的神话与地名由来

## 二、宇宙观与创世

### 高天原（Takamagahara）
- 宇宙最初是混沌状态，天地分离后形成高天原（天上神界）
- 最初诞生三柱独神（造化三神）：
  1. **天之御中主神**（Amenominakanushi）：宇宙中心之神
  2. **高御产巢日神**（Takamimusubi）：高天之产灵
  3. **神产巢日神**（Kamimusubi）：神之产灵

### 伊邪那岐与伊邪那美——造岛创世
- 诸神命伊邪那岐（男）与伊邪那美（女）创造陆地
- 二神站于天浮桥，以天之沼矛搅动海洋，抬起时滴落的盐水凝固成淤能碁呂岛
- 二神降于岛上结合，生出日本诸岛与神明
- 伊邪那美生火神迦具土时被烧伤死去，前往黄泉国

### 黄泉国（Yomi）与禁忌
- 伊邪那岐追妻入黄泉国，约定不可窥视
- 忍不住点火查看，见到腐烂的妻子
- 伊邪那美愤怒，命黄泉女追杀
- 伊邪那岐逃出后，以大石封住黄泉国入口
- 二神之间的对话确立了生死循环：
  > 伊邪那美：我每日将杀死一千人。
  > 伊邪那岐：那我每日将诞生一千五百人。

### 伊邪那岐的祓禊（净化）
- 逃出后在河中洗澡净化污秽（黄泉之汚）
- 洗左眼生出**天照大神**（太阳女神）
- 洗右眼生出**月读命**（月神）
- 洗鼻子生出**素盏鸣尊**（风暴之神）

## 三、主要神祇

### 天照大神（Amaterasu）——太阳女神
- **地位**：日本最高神，天皇家族的始祖神
- **职司**：太阳、高天原统治者
- **重要事迹**：
  - 弟弟须佐之男暴虐无度，天照躲入天岩户（石洞）
  - 世界陷入黑暗，八百万神聚集想办法
  - 天宇受売命（Amenouzume）在洞口起舞，引发众神大笑
  - 天照好奇打开石门，太阳重现
- **神器**：八咫镜（Yata no Kagami），三神器之一

### 须佐之男（Susanoo）——风暴之神
- **职司**：风暴、海洋、诗歌
- **重要事迹**：
  - 被天照逐出高天原后降临出云
  - 斩杀八岐大蛇（八头八尾巨蛇），从尾部得到草薙剑
  - 成为出云的开拓者

### 大国主神（Ōkuninushi）——出云之主
- **职司**：国土经营、医药、农业、姻缘
- **事迹**：曾多次被兄长迫害杀死，多次复活，最终建立出云大社
- **国让**：将地上国度让给天照之孙，条件是建造宏大的宫殿（出云大社）

### 天孙降临——邇邇芸命（Ninigi）
- 天照之孙，奉命降临地上（日向高千穗）
- 携带三神器：八咫镜、草薙剑、八尺琼勾玉
- 其曾孙即为神武天皇（第一代天皇）

### 月读命（Tsukuyomi）——月神
- 伊邪那岐洗右眼所生
- 因杀死食物女神宇迦之御魂，被天照憎恶，日月由此分离（昼夜的起源）

## 四、日本神话的特殊概念

### 八百万神（Yaoyorozu no Kami）
- 日本神道信仰自然万物皆有神灵（神明）
- 山神、河神、树神、石神……每一自然存在皆有神性
- 神明数量约八百万（象征无数）

### 祓禊（Harae）与清净
- 污秽（ケガレ，Kegare）是神道中的核心概念
- 死亡、生育、流血等接触被视为污秽
- 通过仪式净化（祓禊）恢复清净

### 神道宇宙观
- 天界（高天原）→ 人界（葦原中国）→ 根之国/黄泉国
- 神明不是全知全能，而是有情感、有弱点的存在

## 五、对世界观创作的参考价值

| 元素 | 对应概念 |
|------|---------|
| 八百万神（万物皆有灵）| 意识依附任何能吸纳能量的物质 |
| 黄泉国（与人间相通）| 宇宙层级之间的通道与隔断 |
| 天照躲入岩户（世界失去光）| 核心力量缺失导致宇宙崩溃 |
| 三神器（镜剑玉）| 神器三位一体的设定 |
| 国让（强者自愿退让，换取条件）| 谈判与契约在力量关系中的作用 |
| 伊邪那美生死之约（每日千人死千五百人生）| 宇宙中生死/能量的平衡机制 |
