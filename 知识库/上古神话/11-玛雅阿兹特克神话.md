# 玛雅与阿兹特克神话体系

> 玛雅文明约公元前2000年—公元1500年；阿兹特克帝国约公元1300—1521年。

---

## 一、玛雅神话

### 宇宙观与世界结构

玛雅人认为宇宙由多层天界和地下世界构成：

- **十三层天界（Oxlahun Ti Ku）**：每层有神祇守护
- **大地**：漂浮在水上的平面，四角由称为"巴卡布"的神支撑，各司一方
- **九层冥界（Xibalba，"恐惧之地"）**：地下世界，由死亡之神统治

**世界树（Yaxché，绿色神圣木棉树）**：
- 连接天界、大地与冥界
- 树根伸入冥界
- 树梢通往天界
- 树上栖居着雨鸟伊扎姆纳·鸟

**四方与颜色：**

| 方向 | 颜色 | 守护神 |
|------|------|--------|
| 东 | 红 | 太阳升起 |
| 北 | 白 | 死亡 |
| 西 | 黑 | 太阳落下 |
| 南 | 黄 | 丰饶 |
| 中 | 绿/蓝 | 宇宙之树 |

### 《波波尔·乌》（Popol Vuh）

#### 文献介绍

- **原文语言**：基切玛雅语
- **成文年代**：约公元1554—1558年，由基切贵族用拉丁字母记录，原玛雅象形文字版本已失传
- **发现**：1701年，西班牙神父弗朗西斯科·西门尼斯抄录并翻译
- **内容**：玛雅创世神话、英雄双胞胎故事、基切王朝历史
- **意义**：美洲最重要的前哥伦布时代文学作品

#### 多次创世

**第一次创世——泥土人类**

> "随后，创造者、造物主们用土和泥造人，但他们的形体很软，无法站立，湿软坍塌，脸无固定，头朝前倒；他们一说话便没有意义，又很快溶化在水中，无法行走……"

创造者认为此次创造失败，摧毁了泥土人。

**第二次创世——木头人类**

> "随后，用木头作了人像，木头人像男女都有……但他们没有灵魂，也没有理解力，没有记忆力，不记得他们的造物主创造者……他们忘记了内心，忘记了造物主……"

木头人遭到毁灭：大洪水将他们淹没，他们使用的工具（锅、磨盘、狗）纷纷起来反抗他们。幸存者变成了猴子。

**第三次创世——玉米人类（成功）**

> "用黄玉米、白玉米塑造了人的肉，用玉米面团造成了人的手臂和腿……他们开口说话，明白了……他们以完美的眼睛看到了远处，他们的知识变得丰富了……"

#### 英雄双胞胎

最精彩的部分：

**父辈的失败**

胡纳普和维克斯巴兰克是英雄双胞胎的父辈，他们的球赛声惊扰了冥界诸神（西巴尔巴的死神），被诱入冥界，经历各种考验（黑暗屋、寒冷屋、美洲虎屋、火焰屋、蝙蝠屋），最终被杀。胡纳普的头颅被悬挂在树上，化为葫芦，使路过的少女血月受孕，生下英雄双胞胎。

**英雄双胞胎胡纳普与希巴兰克**

双胞胎与黑暗神鸟七鹦鹉（Vucub Caquix）斗智斗勇，将其击败。

随后，双胞胎重走父辈的道路，主动进入冥界：

> "进入黑暗屋，他们不点亮雪茄，以发光的腐木替代；
> 在寒冷屋，他们用草捆和老罗望子来模拟燃烧；
> 冥界的神受骗了，以为他们在遵从规则……"

双胞胎在蝙蝠屋中，胡纳普被裁蝠砍下头颅。希巴兰克用南瓜代替兄弟的头颅，球赛时将真正的头颅夺回。

最终，两人假装死亡，被磨成粉末撒入河中，五天后复活成鱼，再变回人形。他们将自己变成魔术师，杀死了冥界众神，为父辈复仇。

> "他们升入天空，一个成为太阳，一个成为月亮，天空和地球因此被照亮……"

### 玛雅历法

玛雅历法是世界上最精确的古代历法之一：

- **卓尔金历（Tzolkin）**：260天（13个月×20天），宗教历法
- **哈布历（Haab）**：365天（18个月×20天+5天），太阳历
- **长纪历**：计算从公元前3114年8月11日（神话中的创世日）起的天数
- 2012年12月21日：长纪历第五个大周期结束（13巴克顿），误读为"世界末日"，实际是新纪元开始

## 二、阿兹特克神话

### 宇宙观：五个太阳纪

阿兹特克人认为宇宙已经历了四次创造与毁灭，我们现处于第五个太阳纪：

| 太阳纪 | 统治神 | 创造的人类 | 毁灭方式 |
|--------|--------|---------|---------|
| 第一太阳·虎 | 特斯卡特利波卡 | 巨人 | 被美洲豹吞噬 |
| 第二太阳·风 | 魁扎尔科亚特尔 | 人类（吃松果） | 飓风摧毁，人变猴 |
| 第三太阳·雨 | 特拉洛克 | 人类（吃水草种子） | 火雨，人变狗/蝴蝶 |
| 第四太阳·水 | 恰尔奇乌特利克 | 人类（吃野生谷物） | 大洪水，人变鱼 |
| 第五太阳·运动 | 纳纳华津/托纳提乌 | 当今人类 | 大地震（末来） |

### 第五太阳的诞生（神话）

第四太阳灭亡后，众神聚集在特奥蒂瓦坎（"神之城"），决定创造新的太阳：

> "众神聚集，商议：'谁来担当太阳？'
> 尊贵的托纳卡托库特利站出来……
> 身上布满病疖的纳纳华津也站了出来……"

富贵的神焰技托纳卡托库特利恐惧退缩，贫贱的纳纳华津跃入火中，成为太阳（托纳提乌）。太阳却因受伤者无法移动，众神只好献祭自己的血，太阳才开始运动。

**这解释了为何人类必须用鲜血献祭来维持太阳运转**——太阳的诞生本身就建立在牺牲的基础上。

### 魁扎尔科亚特尔神话

羽蛇神的神话最为复杂：

**作为文化英雄**

魁扎尔科亚特尔潜入冥界，偷取人类祖先骨骸，用自己的血与玉米粉混合，创造了现在的人类。

**与特斯卡特利波卡的冲突**

特斯卡特利波卡（黑暗之神）用"烟镜"（黑曜石镜）欺骗魁扎尔科亚特尔，让他看见自己年老丑陋的面容，并诱使他喝下龙舌兰酒，与妹妹乱伦。羞耻的魁扎尔科亚特尔自我放逐：

> "魁扎尔科亚特尔向海洋走去，
> 他一边走，一边哭泣……
> 他在岸边点火自焚，
> 他的灰烬升起，变成了各种美丽的鸟，
> 他的心脏升入天空，变成了金星（晨星）……"

**与西班牙征服的联系**

阿兹特克人预言魁扎尔科亚特尔将在特定年份回归，科尔特斯1519年抵达时恰逢预言之年，使阿兹特克皇帝蒙特祖马二世犹豫不决，助长了西班牙征服。

### 活人献祭的神学意义

阿兹特克活人献祭并非简单的暴力行为，而是建立在完整的宇宙神学基础上：

1. **宇宙债务**：第五太阳诞生时，众神以自身血液维持太阳运动，建立了"宇宙债务"
2. **血液=太阳能量**：人类的鲜血（特别是心脏）被视为太阳的食物，称为"precious eagle cactus fruit"
3. **战士的荣耀**：在献祭中死去被视为荣耀，等同于战死，灵魂将伴随太阳升落
4. **宇宙维持**：如果献祭停止，太阳将停止运动，宇宙将毁灭

**"繁花战争"（Xochiyaoyotl）**：阿兹特克专门发动的战争，目的不是杀死敌人，而是俘虏活人用于献祭。

### 重要文献：《太阳石》（Piedra del Sol）

- **实物**：重约24吨、直径约3.6米的玄武岩圆盘，1790年在墨西哥城大广场地下发现，现藏于墨西哥国立人类学博物馆
- **俗称**"阿兹特克历法石"（虽然并非历法用途）
- **内容**：中央是太阳神托纳提乌的面孔，周围是五个太阳纪的符号、二十天名、宇宙象征

**中央图案解读：**
- 最中心：托纳提乌的面孔，嘴含石燧刀，象征献祭
- 第一环：四个方框，代表前四个太阳纪
- 第二环：二十个日期符号（一个月的每一天）
- 第三环：翡翠（玉石，象征贵重）
- 外环：两条火蛇，代表宇宙时间

### 阿兹特克冥界：九层地下世界

死者须经历九层考验才能到达最终安息地：

| 层级 | 考验 |
|------|------|
| 第1层 | 渡过大河（需要狗帮助，故下葬时随葬狗） |
| 第2层 | 穿越凛风之地 |
| 第3层 | 穿越黑曜石风 |
| 第4层 | 穿越刀风之地 |
| 第5层 | 穿越冰冷之地 |
| 第6层 | 穿越风旗迷阵 |
| 第7层 | 穿越野兽吃心之地 |
| 第8层 | 穿越黑暗之地 |
| 第9层 | 米克特兰，冥界最深处，最终安息 |

**不同死亡方式决定灵魂去处：**
- 战死/献祭而死 → 太阳东升西落，四年后变成蜂鸟
- 溺死/雷击死 → 特拉洛克的天堂（特拉洛坎）
- 难产死亡的女性 → 伴随太阳西行
- 婴儿死亡 → 特殊乐园（奶树之地）
- 普通死亡 → 九层冥界之旅

## 三、比较：玛雅与阿兹特克神话异同

| 方面 | 玛雅 | 阿兹特克 |
|------|------|---------|
| 创世 | 多次创造（玉米人成功） | 五个太阳纪（牺牲维持） |
| 核心神话 | 英雄双胞胎、球赛 | 太阳战争、献祭 |
| 羽蛇神 | 库库尔坎 | 魁扎尔科亚特尔 |
| 历法 | 极精确的多重历法 | 重视太阳纪循环 |
| 献祭规模 | 较少 | 大规模 |
| 球赛 | 神圣仪式，与宇宙对抗相关 | 也有，但不如玛雅核心 |
