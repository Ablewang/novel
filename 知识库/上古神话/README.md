## 跨文化共同主题

### 创世
| 主题 | 代表 |
|------|------|
| 混沌→分离→有序 | 中国（盘古）、希腊（混沌→盖亚）、巴比伦（提亚玛特被劈开）、日本（天地开辟） |
| 原始水域 | 埃及（努恩）、美索不达米亚（阿普苏/提亚玛特）、印度（宇宙之海）、北欧（尼夫尔海姆） |
| 神体化世界 | 中国（盘古化生）、印度（原人歌）、巴比伦（提亚玛特尸体） |

### 洪水神话
几乎所有文化都有大洪水传说：苏美尔（乌特纳比西丁）、《圣经》（诺亚）、印度（摩奴）、中国（大禹治水）、玛雅（第四太阳毁灭）
