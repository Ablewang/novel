# 玛雅与阿兹特克神话体系

## 一、玛雅神话

### 创世神话——《波波尔·乌》（Popol Vuh）

- **年代**：16世纪基切玛雅文字记录，内容可追溯至古典期（250—900年）
- **语言**：基切玛雅语
- **重要性**：中美洲最完整的创世神话文献，被称为"美洲的圣经"

**开篇**：

> *"这是古老的话语，这是波波尔·乌，这里写着一切，是基切人在黑暗中发生的事，在生命的黎明之前，在人类文明出现之前……一切都在宁静中，一切都在平静中，一切都在黑暗中，在夜晚中。只有造物者，只有塑造者，只有特佩乌，只有库库尔坎（羽蛇神），在水中存在……"*

### 三次创世

玛雅神话认为人类世界经历了三次创造与毁灭：

**第一次创造**：用泥土造人，但泥人软弱，无法说话，被毁灭

**第二次创造**：用木头造人，但木人没有灵魂，没有记忆，不知崇拜神灵，被洪水与恶魔毁灭，残存者变为猴子

**第三次创造**（现在的人类）：用玉米面团创造人类，这才成功

**《波波尔·乌》造人片段**：

> *"就是白色玉米粒和黄色玉米粒被用来造人的。这四个创造者——特佩乌、库库尔坎，以及其他神——以这些玉米粒揉成面团，创造了我们最初的祖先……他们能说话，能思考，能看见，能听见，他们走路，他们能抓握……他们感谢造物者和塑造者，感谢那些赐予他们出生的神灵……"*

### 主要神祇

| 神名 | 职能 |
|------|------|
| **伊察姆纳（Itzamna）** | 天空之神，众神之首，书写与日历的创造者 |
| **库库尔坎（Kukulkan）** | 羽蛇神，风、水、金星之神（阿兹特克称魁扎尔科亚特尔） |
| **沙曼（Chaac）** | 雨神，以石斧劈天降雨 |
| **伊希切尔（Ixchel）** | 月亮女神，医术、编织、洪水 |
| **艾（Ah Puch）** | 死亡之神，骷髅形象 |
| **胡纳布·库（Hunab Ku）** | 最高神，无形，宇宙的中心 |

### 时间观与历法

玛雅有全世界最精密的古代历法：

- **卓尔金历（Tzolk'in）**：260天神圣历，用于宗教仪式
- **哈布历（Haab'）**：365天太阳历，用于农业
- **长纪历（Long Count）**：从公元前3114年8月11日（创世日）开始计算，5125年为一大周期

**玛雅宇宙时间轴**：当前为第五个太阳（Sun），前四个太阳皆已毁灭。

## 二、阿兹特克神话

### 五个太阳的传说

阿兹特克（纳瓦特尔语文化）相信世界经历了五个"太阳"（时代）：

| 太阳 | 统治神 | 创造的人类 | 毁灭方式 |
|------|--------|-----------|---------|
| 第一太阳 | 特兹卡特利波卡 | 巨人，以橡果为食 | 被美洲虎吞噬 |
| 第二太阳 | 魁扎尔科亚特尔 | 人类，以松果为食 | 被风吹散，变为猴子 |
| 第三太阳 | 特拉洛克（雨神） | 人类，以水生植物为食 | 火雨毁灭，变为鸟 |
| 第四太阳 | 查尔奇乌特利奎（水神） | 人类，以野生种子为食 | 洪水毁灭，变为鱼 |
| **第五太阳** | 纳纳瓦辛/托纳蒂乌 | 当前人类 | 地震（未来） |

**第五太阳的诞生**（《太阳石传说》）：

诸神在特奥蒂瓦坎（Teotihuacan）聚集，无人敢跳入火中成为太阳。最终，谦逊的麻风病神纳纳瓦辛（Nanahuatzin）勇敢跳入，成为太阳；富有的神托纳蒂乌（Tonatiuh）随后跳入，成为月亮。但太阳不动，需要血液祭祀才肯运转——于是开创了人祭传统。

### 主要神祇

| 神名 | 职能 |
|------|------|
| **魁扎尔科亚特尔（Quetzalcoatl）** | 羽蛇神，风、知识、金星、创造之神 |
| **特兹卡特利波卡（Tezcatlipoca）** | 黑曜石镜神，夜晚、命运、死亡、黑暗之神，与魁扎尔科亚特尔永恒对立 |
| **韦齐洛波奇特利（Huitzilopochtli）** | 战神、太阳神，阿兹特克人的守护神，需要人心与血液维持太阳运转 |
| **特拉洛克（Tlaloc）** | 雨神，农业之神，接收溺水者和被雷击者的灵魂 |
| **科阿特利奎（Coatlicue）** | 大地母神，韦齐洛波奇特利之母，蛇裙形象 |
| **米克特兰特库特利（Mictlantecuhtli）** | 冥界之王，骷髅形象 |

### 重要文献：《门多萨手抄本》与《佛罗伦萨手抄本》

**《门多萨手抄本》**（Codex Mendoza，约1541年）：
- 内容：阿兹特克历史、纳贡制度、日常生活
- 包含特诺奇提特兰城的建立神话

**《佛罗伦萨手抄本》**（Florentine Codex，萨阿贡神父，约1569年）：
- 内容：最完整的阿兹特克文化百科全书，12卷，记录神话、仪式、历史、自然史
- 纳瓦特尔语与西班牙语对照

**神话片段——魁扎尔科亚特尔离开托尔特克**：

> *"魁扎尔科亚特尔，托尔特克人的领袖，在图拉居住了许多年……特兹卡特利波卡来到他面前，给他一面镜子，让他看见自己衰老的容颜。随后给他喝下龙舌兰酒……在醉酒中，他犯了错误，感到羞耻，离开了图拉，向东方而去，誓言有朝一日从东方归来……"*

（历史上，阿兹特克人将西班牙征服者科尔特斯误认为魁扎尔科亚特尔归来）

## 三、对小说创作的参考价值

| 元素 | 中美洲神话概念 | 可借鉴之处 |
|------|--------------|-----------|
| 循环创世 | 五个太阳，每次毁灭后重建 | 宇宙周期性坍缩与重生 |
| 玉米造人 | 人类由神圣物质制造，非泥土 | 不同种族的创造材料决定其本质 |
| 血液驱动太阳 | 太阳需要献祭才能运转 | 能量体系需要持续供给 |
| 对立神 | 魁扎尔科亚特尔与特兹卡特利波卡永恒对立 | 秩序与混沌的双神架构 |
| 历法精密性 | 多套历法叠加，精确到天文级别 | 纪元体系的构建参考 |
