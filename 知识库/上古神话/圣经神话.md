# 圣经神话体系（希伯来·基督教）

## 一、主要文献

### 《创世纪》（Genesis）
- **年代**：约公元前 10–6 世纪成文，内容更古老
- **内容**：宇宙创世、人类起源、大洪水、巴别塔

> **《创世纪》1:1–5（节选）**
>
> *起初，神创造天地。地是空虚混沌，深渊上面一片黑暗；神的灵运行在水面上。神说："要有光"，就有了光。神看光是好的，就把光暗分开了。神称光为"昼"，称暗为"夜"。有晚上，有早晨，这是头一日。*

> **《创世纪》大洪水（6:13–14，节选）**
>
> *神就对诺亚说："凡有血气的人，他的尽头已经来到我面前，因为地上满了他们的强暴，我要把他们和地一并毁灭。你要用歌斐木造一只方舟，分一间一间地造，里外抹上松香。"*

### 《以诺书》（Book of Enoch）
- **年代**：约公元前 3 世纪–公元 1 世纪
- **地位**：次经/伪典，但对天使学影响巨大
- **内容**：守望者（Watchers）天使下凡与人类女性结合，生出巨人（拿非利人）

> **《以诺书》第6章（节选）**
>
> *当那时，当人类的儿女繁殖时，美丽的女儿们降生了。守望者，天上的儿子们，看见她们，渴望她们，彼此说："来，让我们从人类的女儿们中选择妻子，为自己生孩子。"*

### 《约伯记》
- 义人约伯遭受苦难的故事，探讨神义论（苦难存在的意义）

> **神对约伯说（约伯记 38:4–7，节选）**
>
> *我立大地根基的时候，你在哪里呢？你若有聪明，只管说吧。你若晓得就说，是谁定地的尺度？是谁把准绳拉在其上？地的根基安置在何处？地的角石是谁安放的？那时晨星一同歌唱，神的众子也都欢呼。*

## 二、宇宙观与创世

### 六日创世

| 日期 | 创造内容 |
|------|---------|
| 第一日 | 光（昼夜分离） |
| 第二日 | 天空（水域分隔） |
| 第三日 | 陆地、海洋、植物 |
| 第四日 | 太阳、月亮、星辰 |
| 第五日 | 鱼类、鸟类 |
| 第六日 | 陆地动物、人类 |
| 第七日 | 安息 |

### 伊甸园与人类的堕落
- 神用尘土造人（亚当），从亚当肋骨造女人（夏娃）
- 伊甸园中有生命树与知识树
- 蛇诱惑夏娃吃下知识树的果实
- 神的惩罚：女人受产痛，男人劳苦，蛇腹行走，被逐出伊甸园

> **《创世纪》3:19**
>
> *你必汗流满面才得糊口，直到你归了土，因为你是从土而出的。你本是尘土，仍要归于尘土。*

## 三、天使体系

### 天使等级（依据《以诺书》《但以理书》等）

**最高级**：
- **撒拉弗（Seraphim）**：六翼天使，环绕神的宝座，"圣哉，圣哉，圣哉"
- **基路伯（Cherubim）**：守护神宝座与伊甸园，形象为四面四翼

**次级**：
- **权天使（Thrones）**
- **主天使（Dominions）**
- **能天使（Virtues）**
- **力天使（Powers）**

**下级**：
- **执政（Principalities）**
- **天使长（Archangels）**：米迦勒、加百列、拉斐尔、乌列尔
- **天使（Angels）**

### 四大天使长
- **米迦勒（Michael）**：战争与保护，率天军对抗撒旦
- **加百列（Gabriel）**：信息与预言，向玛利亚报喜
- **拉斐尔（Raphael）**：治愈与旅行
- **乌列尔（Uriel）**：光与智慧，看守伊甸园的火焰之剑

## 四、重要神话故事

### 大洪水与诺亚方舟
- 神见人类堕落，决定用洪水毁灭世界
- 唯独义人诺亚蒙恩，奉命建造方舟，带上每种动物一对
- 洪水持续40天40夜
- 方舟停于亚拉腊山，彩虹作为神与人的约定

### 巴别塔
- 人类试图建造通天塔，神担心人类无所不能
- 打乱人类语言，分散至各地

> **《创世纪》11:6–7**
>
> *耶和华说："看哪，他们成为一样的人民，都是一样的言语，如今既做起这事来，以后他们所要做的事，就没有不成就的了。我们下去，在那里变乱他们的口音，使他们的言语彼此不通。"*

### 撒旦的堕落（《以赛亚书》《以西结书》《以诺书》综合）
- 撒旦（路西法）原为最高天使，因骄傲不肯臣服，被逐出天界
- 率三分之一天使堕落，成为魔鬼

> **《以赛亚书》14:12–14**
>
> *明亮之星，早晨之子啊，你何竟从天坠落！你这攻败列国的，何竟被砍倒在地上！你心里曾说："我要升到天上，我要高举我的宝座在神众星以上……我要与至高者同等。"*

## 五、对世界观创作的参考价值

| 元素 | 对应概念 |
|------|---------|
| 知识树（吃了就如神一样）| 能量/知识突破上限的诱惑 |
| 撒旦堕落（骄傲导致毁灭）| 反叛军首领动机的镜像 |
| 天使等级体系 | 宇宙存在等级制度 |
| 守望者与拿非利人 | 高等存在与低等存在的混血后代 |
| 巴别塔（人类试图登天）| 低等宇宙生物试图突破层级 |
| 彩虹之约（神与人的契约）| 不同等级存在之间的协议机制 |
| 末日审判 | 宇宙级别的最终清算 |
