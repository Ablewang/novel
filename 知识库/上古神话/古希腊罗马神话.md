# 古希腊罗马神话体系

> 古希腊神话约形成于公元前8世纪，古罗马神话大量借鉴希腊神话并赋予罗马化名字。

---

## 一、宇宙观与创世

### 混沌开辟

赫西俄德《神谱》开篇：

> "太初，混沌（Chaos）诞生；其次，宽阔胸怀的盖亚（大地）诞生，她是永恒的一切的稳固基础；还有幽暗的塔尔塔洛斯（地底深渊），在宽阔道路大地的最深处；还有爱洛斯（爱），他是不朽神灵中最俊美的……"

从混沌中诞生：
- **厄瑞玻斯（Erebus）**：黑暗
- **倪克斯（Nyx）**：夜
- **盖亚（Gaia）**：大地
- **塔尔塔洛斯（Tartarus）**：深渊

### 世界结构

- **奥林匹斯山**：众神居所
- **人类世界（大地）**：凡人居住
- **冥界（哈迪斯）**：死者的国度，由斯提克斯河、勒忒河等分隔
- **塔尔塔洛斯**：最深处的监狱，关押泰坦神等

## 二、提坦神族与奥林匹斯诸神

### 第一代神祇：乌拉诺斯时代

盖亚与乌拉诺斯（天空）结合，生出十二位提坦神：

| 提坦神 | 领域 |
|--------|------|
| 俄刻阿诺斯 | 大洋河流 |
| 许珀里翁 | 光明 |
| 克里俄斯 | 星座 |
| 科俄斯 | 理智 |
| 伊阿珀托斯 | 凡人的先祖 |
| 克洛诺斯 | 时间，提坦之王 |
| 忒亚 | 天空与光辉 |
| 瑞亚 | 大地母神 |
| 忒弥斯 | 法律与秩序 |
| 摩涅摩绪涅 | 记忆 |
| 福柏 | 月光预言 |
| 忒堤斯 | 海洋 |

乌拉诺斯将怪物子女（独眼巨人、百臂巨人）囚禁于地底。盖亚愤怒，克洛诺斯用镰刀阉割父亲，血落入海中生出阿佛洛狄忒。

### 第二代：克洛诺斯时代

克洛诺斯统治众神，预言说他将被自己的儿子推翻，于是他将每个孩子生下后都吞入腹中。瑞亚将宙斯秘密藏于克里特岛，以石头代替。

宙斯长大后，迫使克洛诺斯吐出兄弟姐妹，展开**提坦战争（Titanomachy）**，历十年，最终奥林匹斯诸神胜利，提坦神被囚塔尔塔洛斯。

## 五、重要神话故事

### 普罗米修斯

普罗米修斯（提坦神）从赫菲斯托斯的火炉中偷取火种，带给人类。宙斯震怒，将他锁于高加索山，每日派鹰啄食他的肝脏（夜晚再生），直至赫拉克勒斯将他解救。

**《神谱》中普罗米修斯的反抗：**

> "普罗米修斯用空心茴香秆盗走了在远方可见的不知疲倦之火，宙斯因此深感痛苦，他的心灵愤怒，见到人类中有了不知疲倦之火就发怒……"

### 潘多拉

宙斯命令赫菲斯托斯用黏土塑造了第一个女人——潘多拉，诸神各赐予她一份礼物（美貌、语言、技能等）。宙斯将她赐给普罗米修斯的弟弟厄庇墨透斯，并附上一个密封的罐子（或箱子）。潘多拉出于好奇打开了它，释放出人类所有的疾病、战争、死亡，只有希望留在了底部。

### 德墨忒尔与珀耳塞福涅

丰收女神德墨忒尔的女儿珀耳塞福涅被冥王哈迪斯劫走带入地下。德墨忒尔悲痛，拒绝让大地生长，天地陷入冬季。

宙斯调解：珀耳塞福涅每年在冥界度过三分之一时间（冬季），其余时间回到母亲身边（春夏秋）。这解释了季节的由来。

### 俄耳甫斯与欧律狄刻

音乐家俄耳甫斯的妻子欧律狄刻被毒蛇咬死。俄耳甫斯以竖琴琴声感动冥府，哈迪斯允许欧律狄刻随他返回，条件是途中俄耳甫斯不得回头看她。将到出口时，俄耳甫斯忍不住回头，欧律狄刻永远消失在黑暗中。

### 珀耳修斯

珀耳修斯（宙斯之子）斩杀美杜莎：
- 雅典娜赠予闪亮盾牌（用以观察倒影而非直视）
- 赫尔墨斯赠予飞行凉鞋
- 从格赖埃伊三姐妹处获得冥王盔（隐身）
- 砍下美杜莎头颅，其血滴化为珀伽索斯（飞马）

归途中，珀耳修斯用美杜莎头颅将欲吞食安德洛墨达的海怪化为石头，救下安德洛墨达。

### 赫拉克勒斯十二功绩

赫拉克勒斯（宙斯与凡女之子）因赫拉诅咒，在疯狂中杀死妻子和儿女，赎罪须完成十二项功绩：

| 序号 | 功绩 |
|------|------|
| 1 | 杀死尼米亚狮子 |
| 2 | 杀死勒纳许德拉（九头蛇） |
| 3 | 捕捉刻律涅亚牡鹿 |
| 4 | 捕捉厄律曼托斯野猪 |
| 5 | 一日清扫奥革阿斯的牛圈（引河水冲洗） |
| 6 | 驱逐斯廷法利斯湖怪鸟 |
| 7 | 捕捉克里特公牛 |
| 8 | 盗取狄俄墨得斯的食人马 |
| 9 | 夺取亚马逊女王希波吕忒的腰带 |
| 10 | 夺取革律翁的牛群 |
| 11 | 从赫斯珀里得斯花园取得金苹果 |
| 12 | 将冥界看门三头犬刻耳柏洛斯带到人间 |

## 六、特洛伊战争

### 起因

婚宴上，不和女神厄里斯扔下金苹果，刻有"献给最美的女神"，赫拉、雅典娜、阿佛洛狄忒争夺。特洛伊王子帕里斯裁判，阿佛洛狄忒贿赂他说会让最美的女人爱上他，帕里斯将苹果给了阿佛洛狄忒。

阿佛洛狄忒帮助帕里斯拐走了斯巴达王墨涅拉奥斯的妻子海伦，引发了特洛伊战争。

### 主要英雄

| 希腊方 | 特洛伊方 |
|--------|---------|
| 阿基里斯（最强战士，踵为弱点） | 赫克托尔（特洛伊第一勇士） |
| 奥德修斯（最智慧） | 埃涅阿斯（后建罗马，维吉尔《埃涅阿斯纪》） |
| 阿伽门农（联军总指挥） | 帕里斯（引发战争） |
| 大埃阿斯（力量） | 普里阿摩斯（特洛伊王） |

### 木马屠城

十年战争僵持，奥德修斯献计：建造巨大木马，希腊精兵藏于其中，假装撤退。特洛伊人将木马拉入城内，夜晚希腊兵从木马中出来，打开城门，特洛伊城破。

## 七、重要文献

### 《神谱》（Theogony）——赫西俄德

- **成书年代**：约公元前700年
- **内容**：系统叙述神祇的谱系与创世过程

**开篇节选：**

> "从赫利孔山的缪斯女神们开始吟唱……
> 她们从宙斯开始，赞颂伟大的宙斯神……
> 还有赫拉，她穿着金色凉鞋，统治阿尔戈斯……
> 以及光辉灿烂的雅典娜……"

### 《工作与时日》——赫西俄德

- **成书年代**：约公元前700年
- **内容**：人类五个时代（黄金时代、白银时代、青铜时代、英雄时代、黑铁时代）

**黄金时代节选：**

> "首先，不朽的神祇们创造了黄金种族的凡人……
> 他们生活得像神一样，心中没有忧愁，
> 远离痛苦和悲伤；
> 可悲的老年不临近他们，
> 他们的手脚永远强健……"

**黑铁时代节选：**

> "他们白天不停地劳作，夜里也不停地劳累，
> 神祇们将给他们带来沉重的烦恼……
> 父亲不与孩子一心，孩子不理解父亲，
> 客人与主人不友好，朋友之间也不友好……"

### 《伊利亚特》——荷马

- **成书年代**：约公元前8世纪
- **内容**：特洛伊战争第十年，阿基里斯的愤怒
- **规模**：24卷，15,693行

**开篇节选：**

> "歌颂那致命的愤怒，女神啊，阿基里斯·珀琉斯之子的愤怒，
> 它给阿开亚人带来了无数的痛苦，
> 将许多英雄强壮的灵魂送入了冥界，
> 让他们的身体成为狗儿和禽鸟的美餐……"

### 《奥德赛》——荷马

- **成书年代**：约公元前8世纪
- **内容**：特洛伊战争结束后，奥德修斯历时十年的归途

**开篇节选：**

> "请告诉我，缪斯，那个聪明的人，
> 他在摧毁特洛伊神圣城堡之后四处漂泊，
> 他看见了许多民族的城市，了解了他们的心灵，
> 他在海上为自己的生命和战友们的归途受尽苦难……"

**主要冒险经历：**
独眼巨人波吕斐摩斯、女巫喀耳刻、塞壬歌声、斯库拉与卡律布狄斯、卡吕普索岛（七年）

### 《变形记》——奥维德（罗马）

- **作者**：奥维德（公元前43年—公元17年）
- **内容**：从创世到凯撒神化，250个神话故事，均涉及变形主题
- **规模**：15卷，11,995行

**创世节选：**

> "我想歌唱那些形态转变的形体，众神啊……
> 在陆地、海洋和天空被创造之前，
> 自然的面貌在整个世界都是一样的，
> 他们称之为混沌——是一团粗糙、无形的物质，
> 什么也不是，只是惰性的重量……"

## 八、冥界详述

### 冥界地理

- **斯提克斯河（Styx）**：冥界边界，亡魂必须渡过；船夫卡戎收取一枚硬币（故希腊人下葬时在死者口中或眼皮上放硬币）
- **勒忒河（Lethe）**：遗忘之河，饮后忘却前世
- **记忆之泉（Mnemosyne）**：另一条河，饮后记得前世
- **极乐世界（Elysium）**：英雄和善人的乐土
- **塔尔塔洛斯**：最深处，惩罚区

### 冥界判官

**三位判官：**
- 米诺斯（克里特国王之灵）
- 拉达曼提斯
- 阿伊阿科斯

**著名受罚者：**
- 西西弗斯：推滚石上山，石头永远滚回（象征徒劳）
- 坦塔罗斯：站在水中，水果挂于头顶，永远无法吃喝（象征渴望）
- 伊克西翁：绑于永转的火轮上
- 达那伊得斯：用无底桶装水（象征无用之功）

## 九、重要神谕与祭祀

### 德尔斐神谕

阿波罗神庙所在，女祭司皮提亚（Pythia）传达神谕，著名案例：
- 俄狄浦斯神谕（弑父娶母）
- 克洛伊索斯神谕（"你将摧毁一个伟大的帝国"——结果摧毁了自己的）

### 奥林匹亚竞技会

每四年举行一次，向宙斯献祭，参赛期间停战，这是奥运会的起源。

## 十、对后世的影响

| 领域 | 影响 |
|------|------|
| 行星命名 | 水金火木土天海冥全部来自罗马神名 |
| 语言 | panic（潘）、music（缪斯）、ocean（俄刻阿诺斯）等 |
| 文学 | 但丁《神曲》、莎士比亚、乔伊斯《尤利西斯》 |
| 哲学 | 柏拉图大量引用神话阐释哲学 |
| 星座 | 黄道十二宫与希腊神话人物对应 |
| 医学 | 蛇杖（赫尔墨斯的双蛇杖、医神阿斯克勒庇俄斯的蛇杖）至今是医学标志 |
