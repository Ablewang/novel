# 凯尔特神话体系（爱尔兰·威尔士）

---

## 一、重要文献

### 1. 《入侵之书》（Lebor Gabála Érenn，爱尔兰）
- **年代**：约11世纪成书（内容更早）
- **内容**：爱尔兰神话历史，记载爱尔兰的六次定居浪潮，包括达努神族（Tuatha Dé Danann）的到来与战争

### 2. 《马比诺吉昂》（Mabinogion，威尔士）
- **年代**：约12—13世纪成书
- **内容**：威尔士神话与传说合集，包含四支《马比诺吉》及亚瑟王相关故事

### 3. 《阿尔斯特传奇》（Ulster Cycle）
- **年代**：约公元前1世纪—公元7世纪
- **内容**：库丘林（Cú Chulainn）等英雄故事

### 4. 《芬尼安传奇》（Fenian Cycle）
- **年代**：约3世纪
- **内容**：芬恩·麦科尔（Fionn mac Cumhaill）与芬尼安战士团的故事

## 二、宇宙创世

凯尔特神话无系统性创世神话（口传文化，基督教化后记录时遭删改）。现存记录中：

- 爱尔兰神话以**六次入侵（定居）**为历史框架
- 最早的定居者是洪水前的**帕索隆（Partholón）**，后被瘟疫灭绝
- 第三批是**弗尔摩里人（Fomorians）**——混沌黑暗神族，代表原始力量
- 第四批是**达努神族（Tuatha Dé Danann）**——光明神族，最重要的神族
- 最后是**盖尔人（Gaels）**——爱尔兰人的祖先，击败达努神族，神族退入地下成为**矮仙（Sídhe）**

## 三、达努神族（Tuatha Dé Danann）——爱尔兰主神

| 神名 | 职司 |
|------|------|
| **达格达（Dagda）** | 众神之父、魔法、农业、智慧，持神棍（能杀死与复活）、神釜（永不匮乏） |
| **努阿达（Nuada）** | 神王，银臂（战斗失去右臂，以银臂代替）|
| **卢格（Lugh）** | 太阳、工艺、诗歌与战争，持神矛，全能之神 |
| **莫里甘（Morrigan）** | 战争、命运、死亡，可化为乌鸦，在战场上方盘旋预言死亡 |
| **布里吉特（Brigid）** | 诗歌、治愈、锻造，达格达之女 |
| **狄安·科赫特（Dian Cecht）** | 医神，为努阿达造银臂 |
| **克里德尼（Credne）** | 金属工匠 |
| **奥格玛（Ogma）** | 语言、书写、力量，发明欧甘文字（Ogham） |
| **玛纳南·麦克利尔（Manannán mac Lir）** | 海洋、冥界、幻觉 |
| **安格斯（Aengus）** | 爱与青春，达格达之子 |
| **波恩（Boann）** | 博因河女神，安格斯之母 |

### 弗尔摩里人（Fomorians）
- **巴罗尔（Balor）**：独眼巨人，其眼光能杀死一切所见之人，卢格之外祖父，被卢格用石弹打穿眼睛杀死
- **科尔马克（Crom Cruach）**：古老神祇，需要活人献祭

## 四、重要神话故事

### 1. 两次马格图瑞德之战（Battles of Mag Tuired）
**第一次**：达努神族到达爱尔兰，与原住民菲尔波格（Fir Bolg）交战，获胜，但神王努阿达失去右臂，按法律不能继续为王。

**第二次**：达努神族与弗尔摩里人大战。伊肯（Elcmar）被驱逐，卢格（Lugh）率军。卢格用投石器射出石弹，打穿祖父巴罗尔的独眼，弗尔摩里人溃败，达努神族获得统治权。

### 2. 库丘林（Cú Chulainn）传说
爱尔兰最伟大的英雄，太阳神卢格之子，本名塞坦达（Sétanta），因杀死铁匠库林（Culann）的猎犬，自愿替代猎犬守护，获名"库林之犬（Cú Chulainn）"。

他能进入狂战状态（Ríastrad，扭曲之怒）：身体变形，发光，一只眼缩入颅内，一只眼突出，身体扭转旋转，进入无敌战斗状态。

库丘林独自抵御康诺特女王梅芙（Medb）的军队，保护阿尔斯特，因对手使用欺诈，最终死于长矛，倚剑而立，死后仍屹立不倒，乌鸦（莫里甘的化身）降落肩头，众人才知他已死去。

### 3. 芬恩的鲑鱼
智者芬内加斯（Finegas）在河中钓到知识之鲑（吃了它便能获得世间一切智慧），命少年**芬恩（Fionn）**烤鱼，嘱咐不可自己吃。芬恩烤鱼时烫伤大拇指，本能放入嘴中，从此获得智慧——每当他将拇指放入嘴里时，便能知晓所需的一切知识。

### 4. 特里斯坦与伊索尔德（凯尔特传说）
康沃尔（Cornish凯尔特）传说，骑士特里斯坦（Tristan）护送爱尔兰公主伊索尔德（Isolde）嫁给康沃尔王马克（King Mark），途中误饮爱情魔药，二人坠入爱河，留下西方文学中最著名的爱情悲剧之一，后来影响了亚瑟王传说。

## 五、威尔士神话（马比诺吉）

### 主要神祇/人物
- **普伊尔（Pwyll）**：戴菲德王子，与冥界之主交换身份一年
- **里安侬（Rhiannon）**：马女神，普伊尔之妻，后被诬陷杀子
- **布兰（Brân the Blessed）**：威尔士神王，持有复活釜
- **马斯（Math）**：魔法师国王

## 六、凯尔特宇宙观

### 他界（Otherworld / Tír na nÓg）
凯尔特神话中最重要的概念之一：

- **蒂尔纳诺格（Tír na nÓg）**："永青之地"，西方极乐仙境，无病无死，时间流逝不同
- **提尔·提尔南·奥格（Tír Tairngire）**："应许之地"
- **马格·梅尔（Mag Mell）**："愉快平原"

他界可以在海洋彼端、地下丘陵内（费丹丘/Sídhe）、或与现实世界重叠。在凯尔特节日**萨温节（Samhain，10月31日，万圣节前身）**，两个世界之间的界限最薄，死者与仙灵可以进入人间。

### 三的神圣性
凯尔特文化对"三"极为崇拜：三联女神（少女/母亲/老妇）、三头神、三重螺旋（Triskelion）等，体现在神话中随处可见的三重结构。

## 七、宇宙观总结

```
凯尔特宇宙（爱尔兰）：
高天原/天界（神灵的最初居所）
    ↓（六次入侵）
人间爱尔兰（达努神族→盖尔人统治）
他界（Otherworld）← 与人间平行存在
    ├── 地下丘陵（Sídhe，被驱逐的神族居所）
    └── 西方极乐岛（蒂尔纳诺格）
```
