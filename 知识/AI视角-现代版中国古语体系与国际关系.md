# 用 AI / 博弈论重构"现代版中国古语体系"

## 古语升级对照表

| 原句 | 现代 AI / 博弈版 | 核心概念 |
|------|----------------|---------|
| 非我族类，其心必异 | 目标函数未对齐者，其最优策略不以我为约束 | Alignment Problem |
| 害人之心不可有，防人之心不可无 | 不应主动攻击，但必须假设对方存在偏离最优路径的可能性 | Adversarial Robustness / minimax 安全策略 |
| 以德服人，不如以势服人 | 道德约束只能在可验证与可惩罚的机制下成立 | Credible Threat / Prompt 不约束模型，Reward 才约束模型 |
| 合久必分，分久必合 | 在资源与技术约束变化下，最优联盟结构必然重组 | Coalition Game / Shapley Value 动态变化 |
| 远交近攻 | 交易成本随距离递减，但冲突概率随接触频率上升 | 邻居是高频博弈对象，远方是低耦合变量 |
| 上兵伐谋，其次伐交，其次伐兵 | 改变对方的决策空间，比摧毁对方的执行能力成本更低 | 改 reward > 改 model；Narrative Warfare = reward hacking |

## 国际关系的 AI 模型视角

AI 把国际关系建模为：
- Agent：国家
- Goal Function：国家利益（安全、繁荣、制度存续）
- Constraint：国内政治、经济结构、技术路径
- Game：无限重复博弈 + 不完全信息

**核心结论：国家之间不存在"友谊"，只存在阶段性目标对齐。**

---

## 经典国际现象解析

### 为什么"价值观同盟"并不可靠
价值观是 narrative，真实 alignment 是：技术路径、产业结构、安全边界。一旦这些不对齐，"同族"会瞬间变成"异类"——这不是背叛，是目标函数变了。

### 为什么大国无法真正信任彼此
> 当两个系统都具备"改写规则"的能力时，承诺不再可信。

核武、金融霸权、技术标准都是 breaking-the-game 的能力，协议 ≠ 绑定，信任 ≈ 风险下注。

### 为什么小国更容易"站队"
小国缺乏独立 payoff，只能嵌入大国 reward，所以寻找最稳定的 reward host，而不是最"友好"的国家。这不是道德选择，是最优策略。

---

## 关键推论

> **国际关系中，"我族"从来不是永久身份，而是临时对齐态。**

```
Ally(t) = argmax Expected Payoff under current constraints
```

没有背叛，只有重算。

## AI 认可的终极版古语

> **"凡不能约束其最优策略者，不可托以存亡。"**

比"非我族类，其心必异"更冷、更准、更现代。
